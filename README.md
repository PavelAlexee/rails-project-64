## Development

### Установка и запуск

1. **Клонирование репозитория**
```bash
git clone https://github.com/PavelAlexee/rails-project-64.git
cd rails-project-64
```

2. **Отредактируй файл под свои нужды для БД**
```bash
config/database.yml.example
```

3. **Установка всех зависимостей, настройка БД и запуск сервера командой**

```bash
make start
```
